# NEXUS-AI
🤖 NexusAI — Central de Inteligência Artificial Plataforma web em HTML, CSS e JavaScript que reúne diferentes ferramentas de IA em uma interface moderna, incluindo ChatGPT, Gemini, Dreamina, Google Flow e Veo 3. Possui chat, geração de imagens e vídeos, central de IAs, gerenciamento de projetos e armazenamento local.
